# bodycha120_72
Zbiorowy moduł dla dokumentacji Smart Home.

## Kioski

- `ha_kiosk` - ekran w holu (Samsung Galaxy Tab 3, x86).
- `ha_kiosk_salon` - ekran w salonie (Xiaomi Redmi Pad, ARM64).
- `ha_kiosk_kuchnia` - ekran w kuchni (Samsung Galaxy Tab 3, x86).
- `ha_kiosk_sypialnia` - ekran w sypialni (Samsung Galaxy Tab 3, x86).

Każdy kiosk jest osobnym repozytorium i podmodułem Git. Katalog budowania Buildozer
jest odseparowany w każdym projekcie jako `.buildozer`.
